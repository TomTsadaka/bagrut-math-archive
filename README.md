# סוכן מאגר שאלוני הבגרות במתמטיקה

בונה מאגר מסווג של **כל שאלות הבגרות במתמטיקה בישראל** — מ-2001 ועד היום.
הסוכן מגלה את השאלונים ברשת, מוריד אותם, קורא כל שאלה, ומסווג אותה.

## מצב נוכחי

| | |
|---|---|
| שאלונים בקטלוג | **794** (2001–2026) |
| הורדו בפועל | **783** |
| מתוכם עם פתרון רשמי | **308** |
| שרטוטים שחולצו | **4,525** |
| 3 / 4 / 5 יח"ל | 339 / 221 / 234 |
| שאלות מחולצות | 1 (דוגמה מאומתת — ראה "מה נותר") |

## איך זה עובד

```
discover  →  fetch  →  extract  →  export
 גילוי       הורדה     חילוץ       ייצוא
```

**1. גילוי** — שני מקורות:
- **API של משרד החינוך** (`meyda.education.gov.il/bagmgr`) — 540 שאלונים מ-2011 ואילך.
  ה-API מחזיר גם קישור ל**פתרון הרשמי** של משרד החינוך לכל שאלון.
- **ארכיון האינטרנט** — 254 שאלונים מ-2001–2010, שכבר לא קיימים באתר החי.
  נמצאו דרך ה-CDX API של Wayback Machine.

**2. הורדה** — מוריד PDF של השאלון + הפתרון, עם מטמון (לא מוריד פעמיים).

**3. חילוץ** — הלב של המערכת. **כל עמוד מרונדר לתמונה ונקרא ויזואלית.**
> למה לא לקרוא את שכבת הטקסט של ה-PDF? כי בשאלוני הבגרות העברית יוצאת
> משובשת והנוסחאות מתפרקות לתווים בודדים בשורות נפרדות. בדקתי — הפלט
> בלתי שמיש. קריאה ויזואלית מחזירה את הנוסח נאמן למקור, כולל שרטוטים.

הפתרון הרשמי נשלח יחד עם השאלון, כדי לדייק את הערכת הקושי והסיווג.

**4. שרטוטים** — השרטוטים בשאלונים הם ציורים וקטוריים, לא תמונות מוטמעות
(`get_images()` מחזיר ריק). לכן `figures.py` אוסף את הנתיבים הוקטוריים,
מאשכל אותם לפי קרבה, מצרף תוויות סמוכות (I, II, x, y), ומסנן מסגרות,
חותמות ודפי טופס. כל שרטוט נחתך ל-PNG ומקושר לשאלה.

**5. ייצוא** — JSON, CSV, דף עיון HTML, דף לפרסום, וניתוח שכיחות.

## הרצה

```bash
pip3 install -r requirements.txt

python3 run.py discover           # גילוי (רץ, 794 שאלונים)
python3 run.py fetch              # הורדה (רץ, 677 ירדו)
export ANTHROPIC_API_KEY=sk-ant-...
python3 run.py extract --limit 10 # חילוץ — התחל בקטן
python3 run.py export             # ייצוא
python3 extract_figures.py        # חילוץ שרטוטים (רץ, 4,525 שרטוטים)
python3 viewer.py                 # דף עיון מקומי
python3 build_artifact.py         # דף לפרסום
```

פקודות שימושיות:

```bash
python3 run.py stats                        # מצב המאגר
python3 run.py topics                       # הטקסונומיה המלאה
python3 run.py search "נגזרת" --units 5     # חיפוש חופשי
python3 run.py search "הסתברות" --difficulty 4
python3 retry_wayback.py 4                  # ניסיון חוזר לשאלונים הישנים
```

## הסיווג

כל שאלה — **וכל סעיף בנפרד** — מסווגת לפי:

| שדה | ערכים |
|---|---|
| `year` | שנה |
| `code` / `units` / `program` | שאלון, רמה (3/4/5), תוכנית לימודים |
| `moed` | קיץ א׳ / קיץ ב׳ / חורף |
| `topic` | 15 נושאי-על |
| `subtopics` | 96 תתי-נושאים |
| `difficulty` | 1–5, לפי רובריקה מפורשת |
| `qtype` | חישוב / הוכחה / חקירה / בעיה מילולית / … |
| `skills` | מיומנויות נדרשות |
| `points`, `est_minutes`, `has_figure` | ניקוד, זמן, שרטוט |

**למה סיווג ברמת הסעיף:** בפרק "שאלות קצרות" כל סעיף הוא נושא אחר לגמרי —
סעיף א׳ גיאומטריה, סעיף ב׳ הסתברות. סיווג ברמת השאלה בלבד היה מאבד את זה.

**רובריקת הקושי** מוגדרת מפורשות ב-`config.py` (1 = הצבה ישירה,
5 = דורש רעיון יצירתי). בלי עוגנים כאלה סיווג קושי הוא רעש.

## קבצים

```
config.py        טקסונומיה, שאלונים, רובריקת קושי
discover.py      גילוי (משרד החינוך + ארכיון האינטרנט)
fetch.py         הורדת PDFים
retry_wayback.py ניסיון חוזר סבלני לארכיון
extract.py       PDF → תמונות → Claude vision → שאלות מסווגות
backfill.py      השלמת מטא-דאטה
figures.py       זיהוי וחיתוך שרטוטים וקטוריים
extract_figures.py הרצת זיהוי השרטוטים על כל המאגר
export.py        JSON / CSV / ניתוח שכיחות / דוח כיסוי
build_artifact.py בניית הדף לפרסום
viewer.py        בניית דף עיון HTML
run.py           נקודת כניסה
data/bagrut.db   SQLite (papers / questions / parts + חיפוש חופשי)
```

## מה נותר

**שלב החילוץ לא רץ עדיין — הוא דורש `ANTHROPIC_API_KEY`**, שלא מוגדר במחשב.
כל שאר הצינור רץ מקצה לקצה. במאגר יש שאלה אחת מאומתת ידנית
(`seed_sample.py`) כדי להדגים את מבנה הפלט.

הערכת היקף: ~677 שאלונים × ~7 עמודים. מומלץ להתחיל ב-`--limit 10`,
לבדוק את איכות הפלט, ורק אז להריץ על הכול.

## מגבלות ידועות

- **2000 חסרה** — הארכיון מכיל מ-2001 ואילך; לא נמצאו קבצי 2000.
- **11 שאלונים טרם ירדו** — ארכיון האינטרנט מגביל קצב (503).
  `retry_wayback.py` מטפל בזה בסבלנות; אפשר להריץ שוב.
- **שאלונים סרוקים** — חלק מהישנים הם סריקות. הקריאה הוויזואלית מטפלת
  בהם, אבל האיכות תלויה בסריקה.
- **סיווג אוטומטי דורש בדיקה מדגמית** — במיוחד `difficulty`.
